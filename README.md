# とけいクエスト

小学3年 算数「時こくと時間」の練習アプリです。時計の針を動かしながら、やさしい順に1ステップずつ練習できます。

**ひらく → https://kawaitomohiro.github.io/tokei-quest/**

- 3つのコース・13ステップ（時こくを もとめる5・たんいの かんさん4・時間を もとめる4）。問題は毎回ランダム
- 時計の針は、ボタンでも指のドラッグでも動かせる。PCはキーボード（数字・Enter・矢印）でも答えられる
- まちがえても責めない。1回目は「考え方」ボタンが光り、2回目で かっこうめの「考え方」に入る
- スコア・れんぞく・メダル（金・銀・銅）・しょうごう
- 名前の登録なし。開けばすぐ始まり、記録と「とちゅうから」は その端末のブラウザの中だけに残る（どこにも送らない）
- 先生の設定（数字の合言葉で入る）：ステップの開き方・問題数・考え方への案内・効果音・文字の大きさ・動き・記録を消す
- 全画面ボタン・文字の大きさ3段・ホーム画面に追加できる。外部の読みこみなし（1枚のHTML）
